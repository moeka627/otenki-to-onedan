# 移動ルート天気・料金表示アプリ

現在地から目的地までのルート、道中/目的地の天気、移動手段ごとの概算料金を 1 画面で確認できるフロントエンド Web アプリです。

## 使い方

1. `index.html` をブラウザで開く（または GitHub Pages にデプロイ）
2. 位置情報の利用を許可して現在地を取得
3. 検索バーまたは地図タップで目的地を選択
4. ルート表示・天気表示・料金表示を確認
5. 移動手段を切り替え、比較表示で料金を見比べる
6. タクシーは「神山町民割引」ON/OFFで表示料金を切り替え可能

## 料金仕様（概算）

- タクシー: `距離(km) × 600円`（神山町民割引 ON 時は 85% OFF）
- 車: `距離(km) × 30円`
- バス: 徳島県内想定の簡易距離料金表
- 電車: 徳島県内想定の簡易距離料金表

## 技術

- HTML / CSS / JavaScript
- Leaflet + OpenStreetMap
- Nominatim（地点検索）
- OSRM（ルート取得）
- Open-Meteo（天気取得）
